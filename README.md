# Diabetes Risk Screening SPA

React + Vite single-page questionnaire for the Early Stage Diabetes Risk Prediction project.

## Run

```bash
npm install
npm run dev
```

The current submit action only logs the form payload and shows a placeholder result.
Next step: connect the submit action to an n8n webhook.

## Dataset

UCI Early Stage Diabetes Risk Prediction:
https://archive.ics.uci.edu/dataset/529/early+stage+diabetes+risk+prediction+dataset
